# voxel-landscape

A voxel landscape flight in the style of Comanche (NovaLogic, 1992) and the PC demos that
followed. This is an original effect in the classic manner, not a port. Everything is software:
320x200 with 256 colours (mode 13h), shown at 4:3, one frame per 70 Hz retrace.

## Build and run

```bash
cmake -S . -B build && cmake --build build -j
./build/voxel-landscape [--scale N]   # Space pause, Esc quit
./build/voxel-landscape --dump DIR [--frames N]   # PPMs at 70 fps
```

## How it works

- **Heightmap.** It is generated by diamond-square (midpoint displacement) on a wrapping
  256x256 grid, from a fixed seed, so it is the same every run. It is normalised to 0-255,
  smoothed once, and flattened to a water level.
- **Colour map.** There are four bands (water, grass with a sandy beach, rock, snow), each with
  16 shades. On land the shade comes from the slope towards a light in the west; under water it
  comes from the depth.
- **Palette.** Indices 0-191 are those 64 colours at 3 fog levels mixed towards the haze colour
  (index = fog·64 + colour). Indices 192-255 are the sky gradient.
- **Rendering.** For each screen column, a ray is marched over the map from near to far, with
  steps that grow by 1.2% so the far distance is cheap. Each sample projects its height to a
  screen row: (camera height − terrain height) × scale / distance + horizon. The distance is
  corrected by cos(ray − view) against the fisheye effect. If that row is above the column's
  y-buffer (the highest row filled so far), the span between them is filled and the y-buffer
  moves up. Near terrain therefore hides far terrain without a depth test, and a column stops as
  soon as it is full. The fog level is chosen by distance.
- **Flight.** The camera follows a wandering path over the wrapping map. Its height eases towards
  the highest ground under it and up to 80 cells ahead. The horizon row moves for pitch and
  tilts with the turn rate for banking.
